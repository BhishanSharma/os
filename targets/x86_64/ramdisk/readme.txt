This is the RAM disk.

GRUB loaded it from the boot medium (boot/ramdisk.img.gz) into memory, so
files work on any PC, even one without an IDE disk. Everything you create or
download here is lost when you reboot.

Type `mount` to see which disk is in use.

Pictures: `view sample.png` or `view testcard.bmp` (PNG, BMP and PPM work).
